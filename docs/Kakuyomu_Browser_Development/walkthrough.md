# 検証手順書: カクヨム専用ブラウザ

## 概要
実装したカクヨム専用ブラウザの動作確認手順です。UIの改善についても確認します。

## 手順
1. **アプリの起動**
   ターミナルで以下のコマンドを実行してください。
   ```bash
   npm run dev
   ```

2. **動作確認項目**
   - [ ] **起動確認**: アプリが起動し、ウィンドウタイトルが「Kakuyomu Browser」になっていること。
   - [ ] **UIの確認**:
     - ヘッダーが白系（半透明）で、カクヨム風の青色がアクセントとして使われていること。
     - URLバーが角丸のデザインになっていること。
     - ナビゲーションボタンにカーソルを合わせた際、背景色が変化する（ホバー効果）こと。
   - [ ] **機能確認**:
     - `https://kakuyomu.jp` が表示されること。
     - ページ遷移時、ヘッダー直下に青い読み込みバー（インジケータ）が表示されること。
     - 「戻る」「進む」「更新」「ホーム」ボタンが正しく動作すること。
     - **広告非表示**: ページ内の広告（バナー等）が表示されていないこと（余白等で確認）。
   
## トラブルシューティング
- `npm run build` でパッケージングエラー（シンボリックリンク作成エラー等）が発生する場合、開発モード `npm run dev` での動作確認を優先してください。
