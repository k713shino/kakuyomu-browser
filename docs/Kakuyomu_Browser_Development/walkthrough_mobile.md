# 検証手順書: モバイル版 (React Native)

## 概要
Android/iOS向けに作成したカクヨム専用ブラウザの動作確認手順です。
Expoを使用しているため、お手持ちのスマートフォン（Expo Goアプリ）で動作確認が可能です。

## 前提条件
- スマートフォンに **Expo Go** アプリがインストールされていること。
  - [iOS (App Store)](https://apps.apple.com/app/expo-go/id982107779)
  - [Android (Google Play)](https://play.google.com/store/apps/details?id=host.exp.exponent)

## 手順
1. **サーバーの起動**
   ターミナルで `mobile` ディレクトリに移動し、Expoサーバーを起動します。
   ```bash
   cd mobile
   npx expo start
   ```

2. **アプリでの確認**
   - ターミナルに表示されたQRコードを、スマートフォンのカメラ（またはExpo Goアプリ）で読み取ります。
   - アプリがビルドされ、スマートフォン上で起動します。

3. **動作確認項目**
   - [ ] **表示**: カクヨムのトップページが表示されること。
   - [ ] **UI**: ヘッダーに「戻る」「進む」「更新」「ホーム」ボタンがあり、アドレスバーが表示されていること。
   - [ ] **ナビゲーション**: 記事をクリックして遷移し、戻る・進むボタンが機能すること。
   - [ ] **広告ブロック**: 広告（バナー等）が非表示になっていること。

## 補足
- PCのエミュレーター（Android Studio / Xcode）がセットアップされている場合は、`a` (Android) または `i` (iOS) を押すことでエミュレーターでも確認できます。
