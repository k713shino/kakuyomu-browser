# 実装計画書: カクヨム専用ブラウザ

## 目標
カクヨム（kakuyomu.jp）を快適に閲覧・利用するための専用ブラウザアプリケーションを開発する。
Electron + Vite + React をベースに、Webviewを用いてカクヨムを表示し、独自のナビゲーション機能を提供する。

## ユーザーレビューが必要な事項
- 特になし（基本機能の実装フェーズ）

## 提案される変更

### Electron設定 (`electron/`)
- **Main Process**: `webview` タグを有効化するため、`webPreferences` の設定を確認・変更する。
  - `webviewTag: true` を設定（セキュリティリスクを考慮しつつ、専用ブラウザとしての用途を優先）。

### UI実装 (`src/`)
- **Layout**: 既存の `App.tsx` を以下の構成に置き換える。
  - **Header**: ナビゲーションボタン（戻る、進む、リロード、ホーム）、URL表示（必要であれば）。
  - **Content**: `webview` タグを使用したブラウザ領域。CSSで画面いっぱいに広げる。

- **Components**:
  - `NavigationParams`: ナビゲーション操作を管理するための状態管理（React state または Ref）。

### 機能要件
- 起動時にカクヨムのトップページ（`https://kakuyomu.jp`）を表示する。
- 外部リンク（カクヨム以外）への遷移時の挙動（デフォルトブラウザで開くか、アプリ内で開くか）を検討。今回は一旦アプリ内遷移を許容する方針。

## 検証計画

### 自動テスト
- 現状のボイラープレートに含まれるテストが通るか確認。
- 新規UIのレンダリングテスト。

### 手動検証
- アプリを起動 (`npm run dev`)。
- カクヨムが表示されるか確認。
- 戻る・進むボタンが正しく機能するか確認。
- 「カクヨム」内のリンクをクリックして遷移できるか確認。

### 広告非表示機能 (`src/App.tsx`)
- **Webview**: `did-finish-load` イベントで `insertCSS` を実行し、一般的な広告セレクタ（Google Ads等）を非表示にする。
    - セレクタ例: `iframe[id^="google_ads_iframe"]`, `.adsbygoogle`, `div[class*="ad-unit"]`
