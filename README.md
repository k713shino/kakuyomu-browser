# Kakuyomu Browser

**Version 0.3.0**

カクヨム専用のデスクトップブラウザアプリケーションです。Electron + React + TypeScript + Vite で構築されており、読書に集中しやすい UI と、作品管理・履歴管理・表示カスタマイズ機能を備えています。

## 主な機能

### ブラウジング
- カクヨム専用ブラウジング
- 広告ブロック
- 縦組み表示のレイアウト補正
- 表示カスタマイズ
  - 広告ブロックの ON/OFF
  - 本文幅の変更
  - 本文文字サイズの変更

### 読書サポート
- 読書履歴の自動保存
- 読書履歴の検索・フィルタ
- スクロール位置の自動保存と復元
- 連続読み（話の終わりに自動で次の話へ移動）
- 読了管理（エピソード単位で読了を記録）
- 読書進捗の可視化（クイックリンク・サイドバー・履歴で進捗表示）
- キーボードショートカット（カスタマイズ可能）

### 音声読み上げ
- AivisSpeech / VOICEVOX / WebSpeech（システムTTS）に対応
- 自動モードでは AivisSpeech → VOICEVOX → WebSpeech の順にフォールバック
- 音量・ピッチ補正スライダー
- 読み上げ位置を読書履歴に保存し、中断後に再開可能
- スピーカー（キャラクター）選択

### クイックリンク
- クイックリンクの保存と解除
- フォルダ対応
- 検索
- エクスポート / インポート
- サイドバー・ドロップダウンからのアクセス
- 作品の更新チェック（未読エピソード数の表示）

### タブ機能
- タブの追加 / 切り替え / クローズ
- ドラッグ&ドロップでの並び替え
- タブの複製
- 前回終了時のタブ復元
- 右クリックメニュー
  - このタブを閉じる
  - 右側を閉じる
  - これ以外をすべて閉じる
  - すべて閉じる

### プロファイル
- プロファイルごとに設定・履歴・クイックリンクを独立管理
- 既存データの自動マイグレーション対応

### 設定バックアップ
- 表示設定・読書履歴・クイックリンク・ショートカットをまとめてエクスポート / インポート

### カクヨム連携
- フォロー中の作品一覧を取得・表示
- 作品ごとの近況ノートを表示

## 変更履歴

### v0.3.0

#### UI/UX の刷新
- ヘッダーボタンをグループ（ナビ・クイックリンク・表示ツール・音声・ユーティリティ）に整理
- ヘッダーに設定ボタンを追加し、クイックリンクを開かなくても設定・管理画面へアクセス可能に
- 読書履歴モーダルをダークテーマからライトテーマに統一
- タブのデザインを刷新（アクティブタブにアクセントライン、閉じる/複製ボタンをホバー時のみ表示）
- クイックリンクサイドバー・ドロップダウンのデザインポリッシュ

#### 音声読み上げ強化・VOICEVOX 対応
- AivisSpeech・VOICEVOX・WebSpeech の3エンジンに対応
- 自動フォールバック（AivisSpeech → VOICEVOX → WebSpeech）
- 音量・ピッチ補正スライダーを追加
- 読み上げ位置を読書履歴に保存し、同エピソードで再開可能に

### v0.2.0

#### 複数プロファイル
- プロファイルごとに設定・履歴・クイックリンクを独立管理

#### 設定バックアップ / 復元
- 全設定をまとめてエクスポート / インポート

#### ショートカットキーカスタマイズ
- 8アクションのキーバインドを設定画面から変更可能

#### カクヨム連携
- フォロー作品一覧の取得・近況ノートの表示

#### 読書体験の向上
- 連続読み（カウントダウン付き自動遷移）
- 読了管理（エピソード単位）
- 作品の更新チェック（未読エピソード数の表示）
- 読書進捗の可視化
- 音声読み上げ・辞書追加機能（AivisSpeech 連携）

## 必要環境

- Node.js
- npm
- Windows 10 / 11

## セットアップ

```bash
npm install
```

## 開発

```bash
npm run dev
```

## ビルド

通常ビルドでは `win-unpacked` を生成します。

```bash
npm run build
```

出力先:

```text
release/0.3.0/win-unpacked
```

インストーラー `.exe` を生成したい場合:

```bash
npm run build:installer
```
