# Kakuyomu Browser

**Version 0.1.0 (初期開発版)**

カクヨム専用のデスクトップブラウザアプリケーション

## 概要

Kakuyomu Browserは、小説投稿サイト「カクヨム」専用のデスクトップアプリケーションです。Electronベースで構築されており、快適な閲覧体験を提供します。

## 主な機能

### 基本機能
- ✨ カクヨム専用ブラウジング
- 🚫 広告ブロック機能（Google Ads、アフィリエイト広告など）

### クイックリンク
- 📑 お気に入り作品の管理（フォルダ対応）
- 💾 クイックリンクのエクスポート/インポート
- 🎯 ドラッグ&ドロップでのリンク整理
- 📱 サイドバー表示

### 読書サポート
- 📖 **読書履歴** - 読んだ作品を自動で記録
  - 最後に読んだエピソードを表示
  - 読んだ回数を記録
  - 履歴から素早くアクセス
- 🔖 **しおり機能** - 読んでいた位置を自動保存・復元
  - スクロール位置を自動記録
  - ページを開くと前回の位置に自動復帰

## 必要環境

- Node.js >= 14.18.0 || >= 16.0.0
- npm

## セットアップ

```bash
# 依存関係のインストール
npm install

# 開発モードで起動
npm run dev

# プロダクションビルド
npm run build
```

## 技術スタック

- **Electron** - デスクトップアプリケーションフレームワーク
- **React** - UIライブラリ
- **TypeScript** - プログラミング言語
- **Vite** - ビルドツール
- **Lucide React** - アイコンライブラリ

## 使い方

### 読書履歴
1. カクヨムの作品ページを開くと自動的に履歴が記録されます
2. ヘッダーの📖アイコンをクリックして履歴を表示
3. 履歴のアイテムをクリックして前回読んでいたページに戻る
4. 個別削除またはすべてクリアも可能

### しおり機能
- 自動的に動作します（設定不要）
- 作品を読んでいるとスクロール位置が自動保存
- 次回同じページを開くと、前回の位置に自動復帰

### クイックリンク
1. お気に入りの作品ページで⭐アイコンをクリック
2. フォルダを作成して整理
3. サイドバー（📱アイコン）から素早くアクセス
